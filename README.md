## 🚀 Featured Projects

### 🤟 [SoundSigns](https://github.com/Waseem21Saleem/SoundSigns) — Speech to Sign Language Translator
> Capstone Project &nbsp;·&nbsp; [Live Demo →](http://soundsigns.xyz)

A full-stack web app that converts spoken English into International Sign Language (ISL) in real-time through a 3D animated avatar. Built to bridge communication gaps for the deaf and hard-of-hearing community.

| Layer | Tech |
|---|---|
| Frontend | React.js, Tailwind CSS, Web Speech API |
| Backend | Python, Flask, Flask-CORS |
| AI | OpenAI GPT-3.5-turbo for gloss translation |
| Output | Pre-rendered 3D ISL avatar videos |

✨ Features: real-time speech recognition · AI-powered gloss translation · seamless video assembly · downloadable output
